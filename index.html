Workforce Scheduling

Optimization-Driven Workforce Scheduling using Constraint Programming

Dec 2025 – Dec 2025 · Université Cadi Ayyad

Modeled and solved an employee assignment problem in production lines using Constraint Satisfaction Problem (CSP) with the Choco Solver in Java. Generated a feasible and optimized work schedule for 500 employees across 21 production lines and 6 shifts, respecting line capacities, flow dependencies, forbidden assignments, and non-repetition constraints.

  • Model 1 – Feasibility Model with AllDifferent and flow constraints
  • Model 2 – Optimization Model minimizing sum of squared line loads
  • Feasible solution found in ~40 seconds with optimization approach
Java Choco Solver CSP Constraint Programming
